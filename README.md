# liplip

واجهة عربية باتجاه من اليمين إلى اليسار لموقع تعلّم لغات موجّه للمستخدمين في العراق. الموقع ثابت ويمكن عرضه من `index.html` أو نشره عبر Cloudflare Pages. لا يحتاج إلى خطوة بناء؛ ملفات النشر في جذر المستودع.

## المسار التجريبي

الصفحة التعريفية ← إنشاء حساب / تسجيل الدخول ← بيانات المستخدم ← اختبار إنجليزي اختياري من خمسة أسئلة ← الرئيسية. زر **دخول سريع كضيف** في تبويب تسجيل الدخول يفتح الرئيسية مباشرة دون بريد أو بيانات شخصية.

الرئيسية تعرض مؤشر المستوى الداخلي A0–C2، وعدد الكلمات المحفوظة والصناديق المكتملة. الدراسة والتحدّث يشتركان في خريطة من **٥ مراحل × ١٠ خطوات × ٢٠ صندوقاً = ١٠٠٠ صندوق**. زر الصندوق الحالي يفتح صفحة «قريباً». في صفحة التحدّث يختار المستخدم **توجيه** أو **تدريب**؛ يظهر بعدها خيارا **محادثة كتابية** و**مكالمة صوتية**، وكلاهما يفتح صفحة «قريباً». الخزانة تعرض الكلمات التي تم تعلّمها؛ لا تُضاف كلمات لمجرد زيارة صفحة الدراسة.

## نموذج التقدّم

`progress.js` يوفّر نموذجاً محلياً مشتركاً للصفحات الأربع. `recordStudy` يُسجّل إكمال الصندوق بالترتيب، والكلمات الفريدة، وتقييمَي النطق والكتابة بعد نشاط حقيقي. `recordChat` يُسجّل تقييمات التواصل واللكنة والطلاقة بعد جلسة حقيقية. هذه الواجهات جاهزة للربط بمحتوى الدراسة والمحادثة مستقبلاً، ولا تستدعيها صفحات «قريباً». `snapshot` يستخرج الصندوق الحالي، الخطوة والمرحلة، وعدد الكلمات، ومتوسطات آخر ٥٠ تقييماً لكل مهارة، ومؤشر المستوى.

مؤشر A0–C2 **داخلي وتجريبي وليس شهادة CEFR أو تحديد مستوى لغوي معتمداً**. يبدأ من A0. يتطلب الانتقال إلى كل مستوى حداً أدنى من الكلمات والصناديق المكتملة، وعدداً كافياً من التقييمات ومتوسطاً أدنى في **كل** المهارات الخمس؛ عتبات `REQUIREMENTS` في `progress.js` قابلة للمراجعة بعد جمع بيانات فعلية والتحقق من صلاحيتها. الاختبار القصير عند التسجيل يعطي نقطة بداية مقترحة منفصلة ولا يرفع مؤشر التقدّم تلقائياً. لا توجد حالياً أنشطة فعلية تمنح كلمات أو تقييمات، لذلك يبقى التقدّم الجديد عند الصفر.

## الحسابات والخصوصية

هذه **نسخة واجهة تجريبية** وليست نظام حسابات حقيقياً. إدخال البريد يمنح وصولاً تجريبياً ولا يتحقق من الهوية. أزرار Google وFacebook وWhatsApp توضّح أن الربط غير مفعّل. تبقى بيانات الملف الشخصي والتقدّم وحالة الضيف في `sessionStorage` ضمن تبويب المتصفح وتُحذف عند الخروج. يمكن للمستخدم تعديل هذه البيانات محلياً، لذا لا تصلح لإثبات التقدّم أو نشر التصنيفات. لا تستخدم النسخة لجمع بيانات مستخدمين حقيقيين.

قبل إطلاق حسابات حقيقية: اربط مزوّد هوية وخزناً آمناً على الخادم، وتحقق من إكمال الأنشطة ونتائج التقييم في الخادم، واضبط OAuth لـ Google وFacebook، وحدّد وسيلة تحقق مناسبة عبر WhatsApp. أضف سياسة خصوصية وموافقة وحذف بيانات وضوابط وصول قبل جمع تاريخ الميلاد والجنس والموقع. يحتاج ادعاء توافق حقيقي مع CEFR إلى تقييم معتمد ودراسة صلاحية منفصلة.

## التطوير والنشر

شغّل `node test/progress.test.js` للتحقق من حدود الخريطة، واشتقاق المستوى، ومسارات الواجهة. في Cloudflare Pages اختر `main`، وإعداد إطار العمل `None`، واترك أمر البناء فارغاً، واجعل مجلد المخرجات `.`. يوجد أيضاً سير عمل للنشر على GitHub Pages إذا كان مصدر النشر في إعدادات المستودع مضبوطاً على GitHub Actions.
