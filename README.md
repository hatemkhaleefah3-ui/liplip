# liplip

واجهة عربية باتجاه من اليمين إلى اليسار لموقع تعلّم لغات موجّه للمستخدمين في العراق. الموقع ثابت ويمكن عرضه من `index.html` أو نشره عبر Cloudflare Pages. لا يحتاج إلى خطوة بناء؛ ملفات النشر في جذر المستودع.

## المسار التجريبي

الصفحة التعريفية ← إنشاء حساب / تسجيل الدخول ← بيانات المستخدم ← اختبار إنجليزي اختياري من خمسة أسئلة ← الرئيسية. زر **دخول سريع كضيف** يفتح الرئيسية دون بريد أو بيانات شخصية.

شريط التنقّل يعرض الأيقونات فقط، بالترتيب: الرئيسية، الدراسة، شاهد واقرأ، خزانتي، تحدّث، الإعدادات. لكل زر اسم قابل للقراءة عبر أدوات الوصول وتلميح عند التركيز أو المرور عليه. على الهاتف يظهر أسفل الشاشة، وعلى الجهاز اللوحي في جانب الشاشة.

الرئيسية تشرح خريطة التعلّم المشتركة: **٥ مراحل × ١٠ خطوات × ٢٠ صندوقاً = ١٠٠٠ صندوق**، وتعرض مؤشر A0–C2 وعدد الكلمات والصناديق المكتملة. صفحات الدراسة، والمحادثة، وشاهد واقرأ تعرض **اسم المرحلة، واسم الخطوة، واسم الصندوق الحالي** مع المستوى الحالي، دون تكرار شرح النظام. للدراسة واجهة دفتر كلمات، وللمحادثة واجهة حوار، وللمشاهدة واجهة عرض، وللقراءة واجهة نص.

الدراسة تفتح درس الصندوق الحالي «قريباً». صفحة شاهد واقرأ تتيح زرَّي **المشاهدة** و**القراءة**، ويؤدي كل منهما إلى صفحة مخصصة «قريباً». في التحدّث يختار المستخدم **توجيه** أو **تدريب**، ثم **محادثة كتابية** أو **مكالمة صوتية**. الخزانة تعرض الكلمات التي تم تعلّمها فعلاً. زيارة أي صفحة لا تمنح تقدماً.

## نموذج التقدّم

`progress.js` يوفّر نموذجاً محلياً واحداً للصفحات. `recordStudy` يسجّل إكمال الصندوق بالترتيب، والكلمات الفريدة، وتقييمَي النطق والكتابة بعد نشاط حقيقي. `recordReception` يسجّل تقييم فهم المسموع بعد مشاهدة فعلية أو تقييم فهم النص بعد قراءة فعلية. `recordChat` يسجّل التواصل واللكنة والطلاقة بعد جلسة حقيقية. هذه الواجهات جاهزة للربط بالمحتوى مستقبلاً ولا تستدعيها صفحات «قريباً». `snapshot` يستخرج الصندوق والخطوة والمرحلة وأسماءها، والكلمات، ومتوسطات آخر ٥٠ تقييماً لكل مهارة، ومؤشر المستوى.

مؤشر A0–C2 **داخلي وتجريبي، وليس شهادة CEFR أو تحديد مستوى لغوي معتمداً**. يبدأ من A0. يتطلب كل مستوى حداً أدنى من الكلمات والصناديق المكتملة، وعدداً كافياً من التقييمات ومتوسطاً أدنى في **كل** المهارات السبع: النطق والكتابة والاستماع والقراءة والتواصل واللكنة والطلاقة. العتبات في `REQUIREMENTS` قابلة للمراجعة بعد جمع بيانات حقيقية والتحقق من صلاحيتها. الاختبار القصير عند التسجيل يحدد نقطة بداية مقترحة منفصلة، ولا يرفع مؤشر التقدّم. لا توجد حالياً أنشطة فعلية تمنح كلمات أو تقييمات؛ لذلك يبدأ التقدّم الجديد من الصفر.

## الحسابات والخصوصية

هذه **نسخة واجهة تجريبية** وليست نظام حسابات حقيقياً. إدخال البريد يمنح وصولاً تجريبياً ولا يتحقق من الهوية. أزرار Google وFacebook وWhatsApp توضّح أن الربط غير مفعّل. تبقى بيانات الملف الشخصي والتقدّم وحالة الضيف في `sessionStorage` ضمن تبويب المتصفح وتُحذف عند الخروج. يمكن تعديل البيانات محلياً، لذا لا تصلح لإثبات التقدّم أو نشر التصنيفات. لا تستخدم النسخة لجمع بيانات مستخدمين حقيقيين.

قبل إطلاق حسابات حقيقية: اربط مزوّد هوية وخزناً آمناً على الخادم، وتحقق من إكمال الأنشطة ونتائج التقييم في الخادم، واضبط OAuth لـ Google وFacebook، وحدّد وسيلة تحقق مناسبة عبر WhatsApp. أضف سياسة خصوصية وموافقة وحذف بيانات وضوابط وصول قبل جمع تاريخ الميلاد والجنس والموقع. يحتاج ادعاء توافق حقيقي مع CEFR إلى تقييم معتمد ودراسة صلاحية منفصلة.

## التطوير والنشر

شغّل `node test/progress.test.js` للتحقق من حدود الخريطة، واشتقاق المستوى، ومسارات الواجهة. في Cloudflare Pages اختر `main`، وإعداد إطار العمل `None`، واترك أمر البناء فارغاً، واجعل مجلد المخرجات `.`. يوجد أيضاً سير عمل للنشر على GitHub Pages إذا كان مصدر النشر في إعدادات المستودع مضبوطاً على GitHub Actions.
